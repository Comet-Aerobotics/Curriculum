# Robotics Simulation & Testing Subcurriculum

> **Track Overview:** Learn how to write ROS 2 launch files, simulate robotic sensors and subsystem kinematics, and validate multi-node action orchestrations without needing physical hardware.

---

## Track Modules

### 1. [Simulation Module 1: ROS 2 Launch Files, Mock Sensors & Mission Simulation](01_launch_files_and_mission_sim.md)
* **Launch Architecture:** Writing modular Python launch descriptions with parameters, namespaces, and node declarations.
* **Mock Sensor Generation:** Simulating real-time load cell weight readings and telemetry streams.
* **Integrated Pipeline Testing:** Running `mission_sim.launch.py` to test autonomous excavation and deposition routines.
